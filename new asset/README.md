# New Asset Library — Improvised OXCEL Website

This directory is a dedicated home for refreshed, production-ready assets intended for the improvised OXCEL website. It is kept separate from the current site's existing `assets/` directory so the original site remains unchanged.

## Folder layout

- `images/` — optimized hero, service, moving/packing, and location photography.
- `logos/` — approved OXCEL logo variations and favicon source files.
- `icons/` — custom SVG icons and UI illustrations.
- `fonts/` — locally hosted web fonts, only when licensing permits.
- `backgrounds/` — decorative textures, patterns, and section backgrounds.
- `documents/` — downloadable brand or service documents used by the improved site.
- `manifest.json` — asset inventory and usage notes.

## Asset standards

- Preserve OXCEL's existing visual identity, colors, spacing, and overall layout when replacing assets.
- Prefer AVIF or WebP for photographic imagery; use SVG for logos and simple icons.
- Provide meaningful, descriptive file names (for example, `hero-household-moving.webp`).
- Optimize file sizes and dimensions for their display context; avoid enlarging small source images beyond their useful resolution.
- Keep useful alt-text and attribution/licensing notes in the manifest or adjacent documentation.
- Do not add placeholder assets to production pages or switch the improvised website to this library until each asset has been reviewed.
- Keep originals intact; put processed versions here rather than overwriting the source files.
