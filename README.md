# OXCEL Website Replica

Responsive, multi-page front-end recreation of publicly accessible pages at [oxcel.net](https://oxcel.net/), intended for QA, learning, and development.

## Pages
- `index.html` — Home
- `packers-movers-pune.html` — Packers & Movers Pune
- `car-transportation-pune.html` — Car Transportation Pune
- `bike-transportation-pune.html` — Bike Transportation Pune
- `packers-and-movers-marathahalli.html` — Packers & Movers Marathahalli
- `packers-movers-whitefield.html` — Packers & Movers Whitefield
- `contactus.html` — Contact

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and open `http://localhost:8000`.
